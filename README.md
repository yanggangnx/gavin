# 要求越多

用网页做的 16:9 横屏 3D 动效短片（1920×1080，30 fps，21 秒），可以逐帧导出成 MP4。

> 本来就想出去玩的时候，给自己、给朋友拍点好看的照片。结果越看测评，要求越多：要全画幅，要专业视频，镜头最好也一步到位。

## 画面

整片只有一个主角：一台相机。浅色影棚里的白色小相机，随着要求增加，长成石墨色的全画幅机身，再装上兔笼、提手、麦克风、监视器和一支大光圈变焦镜头。影棚也从明亮慢慢变暗。

全片唯一的暖色是最开始拍的那几张照片。它们在开头从镜头里飘出来，在监视器里出现一次，最后又回到画面前景。

## 怎么用网页渲染 3D motion 视频

1. **固定画布。** 舞台是一块 1920×1080 的区域：底下一层 WebGL 画布（Three.js）负责 3D，上面一层 HTML 负责文字和标注。浏览器里预览时整体缩放，导出时 1:1 截图。
2. **每一帧都是时间的函数。** `render(t)` 根据时间 `t` 设置相机位置、每个零件的位置、材质颜色和灯光，再渲染一帧。没有物理模拟，没有按真实时间走的动画，随机数也带种子，所以任意一帧都能原样重现。
3. **逐帧导出。** `render.mjs` 在本地起一个小服务器，用无头浏览器打开 `index.html?render`，对第 i 帧调用 `__motion.seek(i / fps)`，截图后通过管道交给 ffmpeg 编码成 H.264。

3D 部分全部用 Three.js 自带的几何体拼出来（圆角盒、圆柱、圆环），没有外部模型文件。影棚反射来自程序生成的环境光（几块柔光箱），照片、屏幕、镜头刻字和传感器都是运行时用 canvas 画的贴图。

Remotion、Motion Canvas 这些工具也是同一个原理：把画面写成时间的函数，再逐帧截图。

## 快速开始

需要 Node 18+ 和 ffmpeg（macOS：`brew install ffmpeg`；Windows：`winget install ffmpeg`）。

```bash
npm install
npx playwright install chromium   # 已装 Google Chrome 可跳过，脚本会自动用它
npm run render                    # → out/yaoqiu-yueduo.mp4
```

有显卡的电脑上导出很快；没有显卡的服务器会用软件渲染 WebGL，大约每帧 1 秒，21 秒的片子要 10 分钟左右。

预览：`npm run preview` 后打开提示的地址。不要直接双击 `index.html`：浏览器不允许从本地文件加载 JS 模块，会改用 CDN 上的 Three.js，断网时就看不到画面。预览页里空格播放/暂停，← → 逐帧，Shift + ← → 跳 1 秒，下方分镜可点击跳转。

更多导出参数：

```bash
node render.mjs --fps 60                 # 60 帧
node render.mjs --from 9 --to 12         # 只导 9–12 秒
node render.mjs --still 19.6             # 导出某一帧 PNG（做封面）
node render.mjs --crf 23                 # 文件更小（默认 18）
node render.mjs --format png             # 中间帧用无损 PNG（更慢）
```

## 改什么在哪

- **文案**：`index.html` 里 `#t1 #t2`（开头）、`#t3`（测评）、`#t4 #i1 #i2 #i3`（要求清单）。
- **节奏**：`render(t)` 里每个 `P(t, 开始秒数, 时长, 缓动)` 就是一段动画；文字的出现时间在 `render` 末尾的 `lineAt(...)`。
- **镜头运动**：`KEYS` 数组，每行是 `[秒数, 水平角, 俯仰角, 距离, 看向的 x, y, z]`，中间自动平滑插值。
- **相机配件**：`build()` 里的 `S.parts`，每个零件写了尺寸、位置、从哪个方向飞入、几秒开始。
- **预算和重量**：`PRICE`、`WEIGHT` 数组。数字只是示意，可按你的实际清单改，不需要可以删掉 `#budget`。
- **配色**：影棚明暗在 `render` 开头的两组渐变色；机身颜色是 `porcelain`（白）和 `graphite`（石墨）。

## 加配乐或配音

导出的视频没有声音。可以在剪映里加，或者用 ffmpeg：

```bash
ffmpeg -i out/yaoqiu-yueduo.mp4 -i bgm.mp3 -c:v copy -c:a aac -shortest out/with-music.mp4
```

如果先录好配音，把每句话的起始秒数填进对应的 `lineAt(...)` 和动画的 `P(t, …)`，画面就能对上节奏。
