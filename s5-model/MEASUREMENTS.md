# 尺寸与参考

模型里所有位置都来自这里：官方尺寸，加上从 Panasonic 产品图上量出来的部件坐标。
代码里的同一组数字在 `src/dims.py`。建模过程中有几处按渲染对比做了修正（取景器凸起的两段斜面和前宽后窄、
握把头部高度、后拨盘凹槽），以 `src/dims.py` 和 `src/body.py` 为准。

参考图：`tools/fetch_refs.sh` 会把 Imaging Resource 上的官方产品图下载到 `ref/`（不提交到仓库）。
量图：`python tools/grid_crop.py <图> x0 y0 x1 y1 <输出.png> [放大倍数] [网格像素]` 给图片叠加像素网格。

## 官方尺寸

| 项目 | 数值 |
| --- | --- |
| 机身 宽 × 高 × 深 | 132.6 × 97.1 × 81.9 mm（深度含取景器眼罩；不含背带环） |
| 机身重量 | 约 714 g（含电池和卡），630 g（仅机身） |
| 卡口 | L 卡口，法兰距 20 mm，内径 51.6 mm |
| 屏幕 | 3.0 英寸侧翻（自由角度）屏，铰链在机身左侧（从背面看在左） |
| 镜头 S-R2060 | 最大直径 Ø77.4 mm，长度 87.2 mm（卡口基准面到镜头前端），滤镜 Ø67 mm，350 g |

## 坐标约定

- 单位毫米（建模时 1 BU = 1 mm，整体放在缩放 0.001 的根空物体下，导出 glTF 才是米）。
- **X 轴 = 光轴所在的竖直平面为 0**；+X 是拍摄者左手侧（无握把一侧），握把在 −X。
- **Y 轴 = 前后**：Y=0 是机身正面（皮纹前表面），镜头朝 −Y，背面在 +Y。
- **Z 轴 = 高度**：Z=0 是机身底面。
- 这样在 Blender 前视图（小键盘 1）里看到的就是相机正面，和 `front.jpg` 方向一致。

## 从参考图量出来的位置（单位 mm，误差约 ±0.5–1 mm）

比例：`front.jpg` 横向 7.134 px/mm（机身 x 33–979 px），纵向按 97.1 mm 总高取 7.22 px/mm；
`top_lens.jpg` 7.066 px/mm（机身 x 42–979 px），光轴在 x=382 px，机身正面 Y=0 在 y=635 px。

**机身外形**
- 机身 X 范围 −84.8（握把侧）到 +47.8；光轴偏离机身中心 18.5 mm（偏向无握把一侧）。
- 机身主体深度：Y 0 → 47.4（背板）；握把最前端 Y ≈ −21.9；眼罩最后端 Y ≈ 60.6。
- 握把在顶视图里的宽度：X −48.6 到 −83.0。
- 顶盖前沿比机身正面靠后约 3 mm（Y ≈ 3.1）；取景器凸起前沿 Y ≈ −1.7，向前盖住卡口座。
- 高度：肩部顶面 Z ≈ 74.5；握把顶部平台 Z ≈ 78；取景器凸起顶面 Z ≈ 94.6；热靴顶 Z = 97.1。
- 正面皮纹上边界 Z ≈ 67（顶盖是光滑漆面，下面是皮纹）；握把皮纹下边界约 Z 6.5，底部是一条漆面窄带。
- 取景器凸起正视为梯形：顶部宽约 X −14.6 → +14.3，向下外扩，侧面约 27° 斜面；
  正面斜面上印 “LUMIX”（Z 约 79–89）。
- 背带环中心：握把侧 X −86.3, Z 71；另一侧 X +50, Z 69.7（三角形金属环）。

**卡口区**
- 卡口中心 X 0, Z 40.2。镀铬卡口环外径约 Ø64.5，黑色凸台外径约 Ø70。
- 卡口环上 6 颗十字螺丝，顶部有触点弧；红色对位点在凸台左下（正视图 X ≈ −26, Z ≈ 18.5）。
- 镜头释放按钮：X ≈ −36, Z ≈ 18.5，Ø 约 8.4，外有下沉圆环。
- 上方 Fn 按钮（正面，握把和卡口之间）：X ≈ −42.7, Z ≈ 53，Ø 约 6.5。
- 自动对焦辅助灯：X ≈ +37, Z ≈ 70.6，Ø 约 3.4。
- “S5” 铭牌：X +26.9 → +40.9，Z 59.6 → 66（下沉小牌，字高约 4.2）。

**顶部**
- 驱动模式拨盘（带红色细环）：中心 X +33.3, Y 19.5，Ø 约 22，高出肩部约 8.6。
  刻有单拍、连拍、6K 照片、自拍等图标。
- 模式拨盘：中心 X −34.1, Y 20.1，Ø 约 23.7；刻 iA P A S M、C1 C2 C3、S&Q、创意视频。
  右侧是 ON/OFF 拨杆（X ≈ −49, Y ≈ 23.6）。
- 快门按钮 + 前拨盘（拨盘套在快门外圈）：中心 X −64.4, Y −13.9；快门 Ø 约 11.3，前拨盘 Ø 约 18。
- WB / ISO / ± 三个按钮：X −57.0 / −65.4 / −74.5，Y ≈ 3.1，Ø 约 6。
- 红色录像键：X −61.9, Y 16.8，Ø 约 7.2（外有深色圈 Ø 9.5）。
- 后拨盘：中心 X −69.1, Y 31.7，Ø 约 19.8；它前方印着焦平面标记 “-φ-”。
- 热靴：X ±10.8，Y 25.6 → 44.0；凸起顶部前方有两个立体声麦克风孔（X ≈ +7.8 和 −7.8, Y ≈ 18.8）。
- 背面顶缘有对焦模式拨杆 S / C / MF（在 AF 模式键旁，约 X −29, Y ≈ 47）。

**背面**（按 `back.jpg` / `back_grip.jpg`，还没逐项量尺寸）
- 大眼罩（圆角矩形橡胶）居中在光轴上；左边是回放键、LVF 键。
- 侧翻屏，左侧铰链座；右侧是 AF ON、摇杆、AF 模式键 + 拨杆、Q 键、后转盘（中间 MENU/SET，四向键）、
  返回/删除键、DISP. 键；拇指位有皮纹。

**侧面**（`sides.jpg`）
- 左侧（+X）：两个接口盖。上：MIC、耳机；下：HDMI（Micro）、USB-C。
- 右侧（握把侧，−X）：双 SD 卡仓门；上方有 “REMOTE” 小盖。

**镜头 20-60（`top_lens.jpg`，从前到后）**
- 前端遮光罩卡口环（带两片小卡扣）→ 对焦环（细竖纹）→ 台阶 → 变焦环（粗竖纹）
  → 焦距刻度带（20 / 24 / 28 / 35 / 50 / 60）→ 固定镜筒：“S” 小方标、竖白线指示、“20-60”、
  “0.15m/0.49ft|min|-∞” → 向卡口收窄，红色对位点。
- 镜筒左侧（拍摄者视角）有 AF / MF 拨杆。
- 前圈上方印 “LUMIX”，下方印 “S 1:3.5-5.6 / 20-60mm Φ67”。

## 用户照片校准

用户提供了正面（带镜头）、顶部、背面、两侧（仓门开、关两种）和翻屏照片。`src/preview.py` 里的 `front_u`、`top_u`、`back_u`
是和这几张照片同比例的正交相机，`python src/render.py -- --blend out/S5_2060.blend --out <目录> --check front_u,top_u,back_u`
渲染后用 `tools/compare.py` 叠图对比。按照片改过的地方：

- 接口一侧的两个接口盖是皮纹面，压印 MIC、耳机图标、HDMI、SS。盖子从前面的皮纹条一直延伸到 Y 40.5。
- SD 卡仓门上有两道竖向滑锁槽和指向机身后方的箭头。
- 顶部 WB / ISO / 曝光补偿按钮半径 3.35，快门半径 4.9；前拨盘下面有一圈底座。
- 握把外侧的上下边缘圆角加大到约 4.6 mm。
- 眼罩从顶上看更方，圆角半径 6.5。
- 屏幕凹位里有一道弧形拨槽（翻屏时可见）。
