# 松下 LUMIX S5（初代）+ S 20-60mm F3.5-5.6 建模交接

需求：初代 S5，装套机 20-60mm，用于高端产品演示的扫光 3D 动画，细节要多。
这份文件是从云端会话交接到本地会话用的：记录了已经确认的尺寸、坐标约定、参考图来源和建模方案。

## 本地环境

1. 安装 Blender（5.x LTS）：`brew install --cask blender`，或从 blender.org 下载。
2. 无界面运行脚本：
   ```bash
   /Applications/Blender.app/Contents/MacOS/Blender -b -P s5-model/build_s5.py -- --out s5-model/out
   ```
   也可以 `pip install bpy==5.2.3`（需要 Python 3.13），在普通 Python 里 `import bpy`。
3. 需要的 Python 包（装进 Blender 自带 Python 或 bpy 所在环境）：`numpy scipy scikit-image pillow`。
4. 参考图：`s5-model/tools/fetch_refs.sh` 下载 Imaging Resource 上的官方产品图到 `s5-model/ref/`（不提交）。
   用户自己下载的照片在 `/Users/yanggang/Documents/Codex/2026-10-28/s/outputs`。
5. 量图工具：`python s5-model/tools/grid_crop.py <图> x0 y0 x1 y1 <输出.png> [放大倍数] [网格像素]`，
   给图片叠加像素网格，方便读坐标。

## 坐标约定（建议沿用）

- 单位毫米（建模时 1 BU = 1 mm，整体放在缩放 0.001 的根空物体下，导出 glTF 才是米）。
- **X 轴 = 光轴所在的竖直平面为 0**；+X 是拍摄者左手侧（无握把一侧），握把在 −X。
- **Y 轴 = 前后**：Y=0 是机身正面（皮纹前表面），镜头朝 −Y，背面在 +Y。
- **Z 轴 = 高度**：Z=0 是机身底面。
- 这样在 Blender 前视图（小键盘 1）里看到的就是相机正面，和 `front.jpg` 方向一致。

## 建模方案

扫光动画最看重三样东西：倒角高光干净、曲面连续、金属/滚花细节经得起特写。按下面的方式分工：

1. **机身外壳（含握把、顶盖、取景器凸起、卡口座）：用 SDF 建模，再用 marching cubes 转成网格。**
   - 每个部件 = 正视、顶视、侧视三个 2D 轮廓的拉伸体求交（“三视图求交”），用 smooth max 做圆角；
     部件之间用 smooth min 融合，做出握把根部等过渡曲面。
   - 2D 轮廓的 SDF 只在 2D 网格上算，再广播成 3D，所以很快。体素 0.2–0.3 mm，圆角半径 ≥ 2 个体素。
   - 皮纹区：皮纹表面向外偏 0.3 mm，边界做小台阶；按面中心所在区域分配材质（漆面 / 皮纹）。
2. **旋转体和机械件直接生成规整网格**：卡口环、拨盘（滚花用角度调制半径生成真几何）、快门、按钮、
   镜头各个环（竖纹用真几何）。
3. **其他细节**：眼罩、屏幕、热靴、接口盖、背带环、螺丝、触点。
4. **文字和标识**：Blender 文字对象转网格，薄浮雕，白色印刷材质；系统字体可用 Inter（LUMIX 字标需横向拉宽）。
5. **材质**：机身细颗粒黑漆（Clearcoat，极细颗粒凹凸）；皮纹（程序化 Voronoi 凹凸）；卡口镀铬（拉丝同心圆）；
   拨盘铝件；橡胶；镜头前组玻璃加镀膜色（紫/绿反射）；屏幕玻璃。
6. **扫光场景**：深色影棚，长条面光沿机身横扫并带关键帧；另放轮廓光，加一盏在镜头前组上扫过的光；Cycles 渲染。
7. **输出**：`.blend`（保留修改器和可编辑部分）、`.glb`、`.fbx`，以及各角度预览图，和参考图并排对比校准。
