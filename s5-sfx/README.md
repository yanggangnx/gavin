# S5 分镜音效

给三个松下 S5 分镜网页（`s5-storyboard` 一镜到底、`ep2` 传感器与录制规格、`ep3` 裁切与固件）编排的运动音效。没有配乐，只有“东西在动”的声音：镜头推拉、元素飞入、数字滚动、列表滚动、强调时的一下冲击。目标是干净、利落、有电影感，留出给配音的空间。

## 原则

- **声音跟着运动走。** 大部分音效不是手放的，而是直接从画面的运动函数算出来：一次移动用的缓动曲线越快的地方声音越响、越亮，声像沿着它的路径走；镜头的推拉速度决定风声大小；年份、价格的里程表数字每翻过一格响一下；固件列表每滚 22 px 一个“拨轮”刻度。所以改了 `T` / `B` 里的节拍时间，声音会自己跟过去。
- **全部现场合成。** 没有采样文件，所有声音都在浏览器里用带种子的噪声和振荡器在 `OfflineAudioContext` 里生成，页面依然是单文件。
- **克制。** 每集只有一两下真正的冲击，其余是很轻的风声和刻度；中间留出静默，冲击才有分量。三集共用同一套音色（同样的推进声、同样的冲击、同一组 A 大调的“玻璃”提示音），听起来是一个系列。

## 文件

| 文件 | 作用 |
| --- | --- |
| `lib/sfx.js` | 音效引擎：乐器、离线渲染、WAV、导出编码、预览播放 |
| `lib/stage.js` | ep2 / ep3 共用的页面引擎，加了音效：预览、导出、`__motion.audio()` |
| `episodes/s5.js` | 一镜到底那页的脚本（它不用 stage.js），加了音效和对应的播放、导出 |
| `episodes/ep2.js`、`episodes/ep3.js` | 两集的脚本，各加了一段 `sfx(s)` 音效编排 |
| `build.mjs` | 把上面这些装回原来的单文件网页 |
| `render.mjs` | 把成品页的音效导出成 WAV，再连同画面导出一个带声音的 MP4 用来审片 |

原始网页里打包了第三方照片和截图（脚本注释里写着不要进 git），所以这里只放脚本，网页本身用 `build.mjs` 生成到 `out/`（不进 git）。

```bash
node build.mjs 原始/s5-storyboard.html 原始/ep2-storyboard.html 原始/ep3-storyboard.html   # → out/*.html
node render.mjs out/ep3-storyboard.html          # → out/ep3-storyboard.wav + .mp4（需要 Playwright 和 ffmpeg）
node render.mjs out/*.html --wav                 # 只要 WAV
```

## 页面上多了什么

- 预览：选项里多了 **音效** 开关（默认开）。播放时画面以声音的时钟为准，不会走着走着对不上；拖动进度条、逐帧都会从当前位置接着放。
- 导出：多了 **带音效** 勾选和 **只导出音效 WAV** 按钮。
  - MP4：浏览器能编码 AAC 就用 AAC（一般是 Mac / Windows 上的 Chrome、Edge），不能就用 Opus（有些剪辑软件读不了 MP4 里的 Opus，这时用 WAV）。
  - WebM：Opus。
  - PNG 序列：同一个文件夹（或 ZIP）里附一个 `*-sfx.wav`。
  - 进剪辑软件，建议用 PNG 序列 + WAV，或视频 + 单独导出的 WAV，从第 0 帧对齐即可。在无头 Chromium 里实测，导出的 WebM、MP4（Opus）和 WAV 逐采样对齐。
- `?render` 模式下 `window.__motion.audio()` 返回 base64 的 24-bit WAV，自己的 render.mjs 要出带声音的成片可以直接拿：`ffmpeg -i video.mov -i sfx.wav -c:v copy -c:a pcm_s24le out.mov`。

## 音色

| 乐器 | 声音 | 用在 |
| --- | --- | --- |
| `move` | 沿缓动曲线的气流声，带通噪声，速度越快越响越亮，声像沿路径移动 | 元素飞入、缩放、推进卡口 |
| `camera` | 镜头本身的运动：平移和推拉速度决定大小，推近变亮、拉远变暗，慢漂移不出声 | 拉远看八台机身、镜头移向 S5 |
| `air` | 任意运动的气流，电平 / 频率 / 声像逐点给出 | 时间轴播放头、列表滚动 |
| `hit` | 冲击：下滑的超低频 + 低频冲压 + 中低频“敲击”（手机外放能听到的部分）+ 高频瞬态 + 暗色混响尾 | 每集的关键数字 |
| `thud` | 小一号的落定 | 数字落位、裁切框到位 |
| `tick` | 机械刻度，像相机拨盘的一格 | 里程表翻格、表格行、列表滚动 |
| `ping` | 玻璃般的泛音，高泛音先衰减；只用 A 大调里的音（880 / 1318.5 / 1760 / 2637 Hz） | 被单独点出来的那一项 |
| `swell` | 反向渐强，在冲击那一刻戛然而止 | 每个大冲击之前 |
| `drop` | 沿缓动曲线下滑的低音，感觉多于听到 | 价格下落、“不是卖点” |
| `scribe` | 细细的划线声 | 描边、下划线 |
| `puff` | 一口低频的气，表示消散 | 红色的“1”消失 |
| `bloom` | 从暗处升起的低频和暗色气流，纯正弦，不会变成一个音高 | 开场、机身浮现 |

## 混音

- 48 kHz 立体声，所有声音统一过一个约 1.9 秒、偏暗的厅堂混响；200 Hz 以下不进混响，低频保持干净。
- 层级：每集的核心冲击峰值约 −3 ~ −4 dBFS，次一级冲击 −7 ~ −9，风声 −15 ~ −30，刻度 −25 ~ −37。
- 实测整体响度：一镜到底 −23.9 LUFS、ep2 −25.6、ep3 −23.7，真峰值都在 −3 dBFS 以下，给后加的配音留了空间。配音录好后，在剪辑软件里整体再调即可。
- 声像跟着画面位置走，但限制在 ±0.8 之内，不会只在一只耳朵里。

## 怎么改

- **配音录好后重新对时间：** 只改各集的 `T` / `B`，声音跟着走。
- **改单个音效：** 在该集的 `sfx(s)` 里找对应的那一行。`db` 大约就是峰值电平，`pan` 是声像（−1 左、1 右），`f` 是频率。
- **想更安静或更“干”：** 整体电平改 `lib/sfx.js` 里 `Session` 的 `master`，混响多少改 `ret`。
- **听和看：** `render.mjs` 输出的 MP4 就是带声音的审片版；`out/*.cues.json` 是每个音效的时间表。
