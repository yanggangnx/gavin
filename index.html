导出 MP4

画面里没有 CSS 动画和定时器，每一帧都由时间 t 算出来。导出时脚本逐帧跳到 t、截图，再交给 ffmpeg 合成，帧率不受电脑快慢影响。在仓库目录运行：

npm install
npx playwright install chromium
npm run render

需要本机装有 ffmpeg。输出到 out/yaoqiu-yueduo.mp4；加 -- --fps 60 出 60 帧。
