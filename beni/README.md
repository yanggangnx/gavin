# Beni 运动性能一览

Beni 跟拍机器人运动性能一览的 16:9 动态页面，一镜到底，共 4.5 秒：1.5 秒运动，3 秒静止。页面里可以选分辨率、帧率、运动模糊、快门角度、胶片颗粒、暗角和缓动曲线，并直接导出 MP4。

## 画面

- **0–1.5 秒**：黑场亮起，镜头从右向左横移入画，带运动模糊。参数行从上到下依次落位，表格线从左向右画出，最高时速从 0 计到 28.8。
- **1.5–4.5 秒**：版面完全静止，只有 Beni 在动。
- **Beni**：全程按官方动画原速（30 fps）播放，没有慢放、没有帧间融合。入场时摆动、侧头一瞥，版面落定时转头看向镜头，静止段再转开、转回，最后一帧正对镜头。
- **版式**：上下两条通栏线框住整页。标题在左，右侧同一基线放产品名“Beni 智能跟拍机器人”。下面左边是 8 行参数，右边是 Beni，站在底线上。最高时速一行加高、字号加大、用强调色。
- **字号**：只用一套克制的字号：标题 46，时速数字 64，数值 24，标签 19，注释 18（按 1920×1080 计）。字重以 Regular 为主，标签字距放宽；每行的标签、数值和注释共用一条基线。
- **质感**：深灰影棚渐变，加轻微胶片颗粒和暗角。

| 参数 | 数值 |
| --- | --- |
| 最高时速 | **28.8 km/h** · 17.9 mph |
| 越障跳跃 | 25 cm · 10 英寸 |
| 自动起身 | 支持，翻倒后自动站立，继续追踪 |
| 智能避障 | 前置双广角视觉传感器 |
| 跟随运镜 | 后向 · 侧向平行 · 360° 环绕 |
| 电池续航 | 1.5 h / 块，可插拔 |
| 机身重量 | 1.8 kg |
| 机身尺寸 | 21.5 × 18 × 18 cm |

数据全部来自合作 Brief 的卖点和参数对照表。

## 打开

- **直接双击 `index.html`**。产品画面在 `frames.js` 里，不需要本地服务器，导出也能用。字体来自 Google Fonts，断网时会退回系统字体。
- 或者在仓库根目录运行 `npm run preview`，然后打开 `/beni/`。
- 需要单个文件发给别人时，运行 `npm run beni:single`，生成 `out/beni-overview.html`（约 5 MB）。页面、产品画面和 MP4 编码器都打包在这一个文件里，双击就能打开和导出。

快捷键：空格播放/暂停，← → 逐帧，F 全屏。时间轴上红色是 1.5 秒运动段，灰色是 3 秒静止段。

## 渲染设置和导出

| 选项 | 可选值 | 默认 |
| --- | --- | --- |
| 分辨率 | 1280×720 / 1920×1080 / 2560×1440 / 3840×2160 | 1920×1080 |
| 帧率 | 24 / 25 / 30 / 50 / 60 | 60（Beni 素材是 30 fps，选 30 或 60 才能逐帧对齐，其他帧率会轻微跳帧） |
| 运动模糊 | 关 / 4 / 8 / 16 次采样 | 8 |
| 快门角度 | 90° / 180° / 270° / 360° | 360°（60 fps 下拖影清楚可见） |
| 胶片颗粒 | 0–100 | 30（轻微） |
| 暗角 | 0–100 | 50 |
| 缓动曲线 | 电影 / 标准 / 柔和 / 利落 | 电影：镜头 `cubic-bezier(0.76, 0, 0.24, 1)`，落位 `cubic-bezier(0.16, 1, 0.3, 1)` |
| 码率 | 自动 / 8–80 Mbps | 自动：约 0.2 bit/像素/帧，1080p60 约 25 Mbps |

- 画面按 1920×1080 设计，等比缩放到所选分辨率，文字和线条都按原生分辨率绘制。
- 运动模糊在快门时间内多次采样后取平均，只作用在镜头横移上：Beni 的姿态按输出帧取，不会把两个姿态叠在一起。静止段只采样一次。
- 预览也按所选帧率步进，看到的就是导出的样子。

“导出 MP4”在浏览器里逐帧渲染，再用 WebCodecs 编码成 H.264；浏览器不支持 H.264 时退回 VP9 / AV1，封装用 `vendor/mp4-muxer.js`。导出速度取决于电脑性能，和实时播放流畅与否无关。不支持 WebCodecs 的浏览器会改为实时录制（WebM），录制期间页面需要保持在前台。

产品画面源素材中机身约 780 px 高，1080p 下是缩小显示，很清晰；4K 下机身约放大 1.6 倍，文字和线条仍是原生 4K。

也可以用仓库根目录的逐帧渲染脚本（需要 Node 18+ 和 ffmpeg）：

```bash
npm run beni:render                                                          # → out/beni.mp4，1080p60，8 次运动模糊
node render.mjs --page beni/index.html --size 3840x2160 --fps 30 --blur 16  # 4K30
node render.mjs --page beni/index.html --still 3                             # 某一帧 PNG
```

## 素材和 Beni 的动作

产品画面用的是官网（mondorobotics.com）产品页的移动端渲染序列帧（1170×1800，透明背景）。Brief PDF 里的产品图只有 538 px，不够全屏使用。

- **原速播放**：序列按 30 fps 播放（空翻的滞空时间正好对应 25 cm 跳高，说明原片是 30 fps）。60 fps 输出时每个源帧正好显示两次，30 fps 时一一对应，不慢放、不插帧、不融合，所以不会掉帧或出重影。
- **动作路线**：用第 93–146 帧（空翻落地后的待机动作），4.5 秒正好 135 帧：93 → 146（摆动、侧头一瞥、转头看镜头），回放到 105（转开），再到 146（转回来）。两处折返都在 Beni 几乎静止的帧上（146 已站定，105 动作很慢），看不出倒放；最后一帧正对镜头。
- **为什么不慢放**：转头在原片里只有 6 帧，放慢后只能逐帧停顿或帧间融合，看起来就是掉帧或重影；用光流补帧也试过，耳朵和眼眶边缘有涂抹。
- **打包方式**：`tools/pack_frames.py` 把这 54 帧裁到可见区域，淡化贴到画面边缘的地面阴影，压成 WebP 写进 `frames.js`。用 base64 存，所以双击打开也能导出。

导出 MP4 时整段只放一个关键帧。之前每 2 秒一个关键帧，胶片颗粒会在关键帧处轻微“跳”一下。

## 改什么在哪

都在 `index.html` 的脚本里：

- **参数行**：`ROWS`。
- **版式**：`L`、`R`（左右边距）、`TOP`、`BOT`（上下两条通栏线）、`TR`（表格右边界）、`VX`（数值列），`ROBOT`（Beni 站的位置和缩放）。
- **节奏**：`MOTION = 1.5`、`HOLD = 3.0`；横移距离 `TRUCK`；每行落位的先后在 `drawPage`。
- **Beni 的动作**：`PATH`（源帧路线，按 `SRC_FPS = 30` 播放）。
- **曲线**：`CURVES`。
- **配色**：强调色 `ACCENT`，背景在 `drawBackground`，文字样式在 `ST`。

# 第二支：Beni 影像参数（`imaging.html`）

同样风格的取景器样式页面，同样是 1.5 秒运动加 3 秒静止，共 4.5 秒。双击 `imaging.html` 打开，渲染设置和导出与第一支完全相同。

## 画面

- **0–0.2 秒**：黑场亮起，停在 Beni 头部特写。
- **0.2–1.5 秒**：按官方动画原速（30 fps）一路推进 Beni 的镜头，1.5 秒正好落在镜头玻璃上。60 fps 下每个源帧正好显示两次，没有慢放和帧间融合。取景器界面同时亮起，变焦读数跟着推进从 1× 走到 2×。
- **1.5–4.5 秒**：版面完全静止，以下元素保持在动，都是连续平滑的变化，不靠换帧：
  - 镜头画面整张极慢地推近，3 秒放大 4%；
  - REC 点呼吸；
  - 时间码走字；
  - 麦克风电平跳动。
- **版式**：
  - 四角取景框，中心十字对准光圈；
  - 左上 REC 和时间码，右上“影像参数 / Beni 智能跟拍机器人”；
  - 主信息“HDR · 4K 60fps”放在镜头右侧的暗部，下面一行小字“超高清录制 · 3K 60fps 可选”；
  - 其余 5 项排成底部参数栏。
- **字幕阴影**：所有界面文字带一层很淡的暗影，像相机屏幕上的字幕。推进经过白色面板时也看得清，在深色镜头上看不出来。

| 位置 | 参数 | 说明 |
| --- | --- | --- |
| 主信息 | HDR · 4K 60fps | 3K 60fps 可选 |
| 参数栏 | 10-bit | 10 亿+ 色彩 |
| 参数栏 | 1/1.3″ CMOS | 传感器 |
| 参数栏 | 1080P 120fps | 慢动作 |
| 参数栏 | 2× | 电子变焦（带 1×→2× 读数） |
| 参数栏 | 外接麦克风 | 支持第三方麦克风（带电平表） |

数据全部来自合作 Brief。画面是官网产品序列帧里推进镜头的一段（第 220–259 帧），不是 Beni 拍的样片。

## 文件

- `imaging.html`：页面本体。
- `imaging-frames.js`：40 帧推进画面（`tools/pack_lens_frames.py` 生成）。运动中的帧最宽 1920 px；停留的第 259 帧保留 2880 px，4K 输出也清晰。
- 单文件版：`npm run beni:imaging:single` → `out/beni-imaging.html`（约 5.4 MB）。
- 命令行逐帧渲染：`npm run beni:imaging:render` → `out/beni-imaging.mp4`。

改内容都在 `imaging.html` 的脚本里：`CELLS`（底部参数栏）、`drawHUD`（各元素的位置和入场时间）、`HX` / `HERO_Y`（主信息位置）、`LENS0` / `LENS1` / `DIVE_AT`（推进用哪几帧、何时开始）。
