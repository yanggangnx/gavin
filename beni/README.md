# Beni 运动性能 · 一镜到底

Beni 跟拍机器人运动性能参数的 16:9 网页动态演示：11 段，每段 1.5 秒运动、3 秒静止，加 1.5 秒收尾淡出，共 51 秒。全程一个镜头不切：Beni 从远处驶来、起跳空翻、落地转身、推近到镜头、穿过镜头再退出来，参数跟着镜头依次出现。

页面里可以选分辨率、帧率、运动模糊、快门角度、胶片颗粒、暗角和缓动曲线，并直接导出 MP4。

## 打开

- **直接双击 `index.html`**。产品画面都在 `frames.js` 里，不需要本地服务器，导出也能用。字体来自 Google Fonts，断网时会退回系统字体。
- 或者在仓库根目录 `npm run preview`，打开提示地址下的 `/beni/`。

空格播放/暂停，← → 逐帧，Shift + ← → 跳到上一段/下一段，F 全屏。时间轴上红色是 1.5 秒运动段，灰色是 3 秒静止段。

## 资料归纳

Brief 里和运动有关的参数只在卖点和参数对照表两处。Beni 和 Beni Lite 的运动性能完全一样，只有重量差 50 g。影像参数（4K60、10-bit、2 倍变焦）不属于运动性能，本片不讲。

| 参数 | Beni | Beni Lite |
| --- | --- | --- |
| 最高时速 | 17.9 mph（28.8 km/h） | 相同 |
| 越障跳跃 | 10 英寸（25 cm） | 相同 |
| 自动起身 | 具备 | 具备 |
| 智能避障 | 前置双广角视觉传感器 | 相同 |
| 智能跟随 | 深度多角度锁定 | 相同 |
| 跟随运镜 | 后向 · 侧向平行 · 360° 环绕（Orbit） | — |
| 电池续航 | 1.5 h / 块，可插拔 | 相同 |
| 机身重量 | 1.8 kg | 1.75 kg |
| 机身尺寸 | 21.5 × 18 × 18 cm | 相同 |

时速是全片重点，给了两段：一段看数字和刻度，一段换算成能感知的量（28.8 ÷ 3.6 = 8.0 m/s；1 km ÷ 8 m/s = 125 s，即配速 2′05″/km）。最后的参数表里它也是唯一高亮的一行。

## 节奏和曲线

- 每段前 1.5 秒内完成全部运动：镜头和产品移动、旧文字退场（0–0.5 秒）、新文字依次入场（约 0.4–1.5 秒）、数字计数。之后 3 秒画面完全静止，只有胶片颗粒。
- 曲线都是 CSS 同款 `cubic-bezier`，默认“电影”预设：镜头 `cubic-bezier(0.76, 0, 0.24, 1)`，入场 `cubic-bezier(0.16, 1, 0.3, 1)`，出场 `cubic-bezier(0.7, 0, 0.84, 0)`。渲染设置里还有“标准 / 柔和 / 利落”三组可换。
- 空翻是例外：空翻序列帧之间姿态差别太大，插值会出重影，所以按原速播放（约 17 帧/秒），在最高点直接定格。

## 渲染设置和导出

| 选项 | 可选值 | 说明 |
| --- | --- | --- |
| 分辨率 | 1280×720 / 1920×1080 / 2560×1440 / 3840×2160 | 画面按 1920×1080 设计，等比缩放，文字和线条在任何分辨率下都是清晰的矢量 |
| 帧率 | 24 / 25 / 30 / 50 / 60 | 预览也按这个帧率步进，所见即所得 |
| 运动模糊 | 关 / 4 / 8 / 16 次采样 | 每帧在快门时间内多次采样后平均；静止段自动跳过 |
| 快门角度 | 90° / 180° / 270° / 360° | 180° 是标准电影快门 |
| 胶片颗粒、暗角 | 0–100 | 颗粒每帧变化 |
| 缓动曲线 | 电影 / 标准 / 柔和 / 利落 | 左侧小图是镜头曲线 |
| 码率 | 自动 / 8–80 Mbps | 自动约为 0.2 bit/像素/帧（胶片颗粒很吃码率），1080p60 约 25 Mbps，范围 8–100 Mbps |

“导出 MP4”在浏览器里逐帧渲染再用 WebCodecs 编码成 H.264（不支持 H.264 时退回 VP9 / AV1），封装用 `vendor/mp4-muxer.js`。导出速度取决于电脑，和实时播放是否流畅无关。不支持 WebCodecs 的浏览器会改为实时录屏（WebM），这时需要让页面保持在前台。

产品画面的源素材约 1440p（2880×1600 序列帧裁切后按需缩小），4K 输出时产品是放大采样，文字和图形仍是原生 4K。

也可以用仓库根目录的逐帧渲染脚本（需要 Node 18+ 和 ffmpeg）：

```bash
npm run beni:render                                                            # → out/beni.mp4，1080p60，8 次运动模糊
node render.mjs --page beni/index.html --size 3840x2160 --fps 30 --blur 16    # 4K30
node render.mjs --page beni/index.html --still 6                               # 某一帧 PNG
```

## 素材

产品画面用的是官网（mondorobotics.com）产品页的同款渲染序列帧（2880×1600，透明背景）：驶入、空翻、转身、推近镜头、穿入镜头。Brief PDF 里的产品图只有 538 px，放到 16:9 全屏会糊。`tools/pack_frames.py` 把用到的 181 帧裁到可见区域、压成 WebP，写进 `frames.js`（base64，所以双击打开也能导出）。

## 改什么在哪

都在 `index.html` 的脚本里：

- **文案和数字**：`BEATS` 数组，每段的 `els` 是这一段的文字、数字、刻度和示意图，坐标按 1920×1080。
- **镜头和产品位置**：每段的 `cam`（源画面中的点 `ax, ay` 落到屏幕 `x, y`，缩放 `k`，用第 `f` 帧）；特殊段落（空翻、穿过镜头、退出镜头）有自己的 `path`。
- **节奏**：脚本顶部 `MOTION = 1.5`、`HOLD = 3.0`。
- **曲线**：`CURVES`。
- **配色**：强调色 `ACCENT`，背景在 `drawBackground`，文字样式在 `ST`。
