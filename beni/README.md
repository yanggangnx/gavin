# Beni 运动性能一览

Beni 跟拍机器人运动性能一览的 16:9 动态页面，一镜到底，共 4.5 秒：1.5 秒运动，3 秒静止。页面里可以选分辨率、帧率、运动模糊、快门角度、胶片颗粒、暗角和缓动曲线，并直接导出 MP4。

## 画面

- **0–1.5 秒**：黑场亮起，镜头从右向左横移入画，带运动模糊。参数行从上到下依次落位，表格线从左向右画出，最高时速从 0 计到 28.8。
- **1.5–4.5 秒**：版面完全静止。只有 Beni 在原地慢慢转头，再看回镜头。4.5 秒正好转一个来回，循环播放没有接缝。
- **版式**：上下两条通栏线框住整页。标题在左，右侧对齐“Beni 与 Beni Lite 运动性能一致，仅重量不同”。下面左边是 8 行参数，右边是 Beni，站在底线上。最高时速一行加高、字号加大、用强调色。
- **质感**：深灰影棚渐变，加轻微胶片颗粒和暗角。

| 参数 | 数值 |
| --- | --- |
| 最高时速 | **28.8 km/h** · 17.9 mph |
| 越障跳跃 | 25 cm · 10 英寸 |
| 自动起身 | 支持，翻倒后自动站立，继续追踪 |
| 智能避障 | 前置双广角视觉传感器 |
| 跟随运镜 | 后向 · 侧向平行 · 360° 环绕 |
| 电池续航 | 1.5 h / 块，可插拔 |
| 机身重量 | 1.8 kg（Beni Lite 1.75 kg） |
| 机身尺寸 | 21.5 × 18 × 18 cm |

数据全部来自合作 Brief 的卖点和参数对照表。

## 打开

- **直接双击 `index.html`**。产品画面在 `frames.js` 里，不需要本地服务器，导出也能用。字体来自 Google Fonts，断网时会退回系统字体。
- 或者在仓库根目录运行 `npm run preview`，然后打开 `/beni/`。

快捷键：空格播放/暂停，← → 逐帧，F 全屏。时间轴上红色是 1.5 秒运动段，灰色是 3 秒静止段。

## 渲染设置和导出

| 选项 | 可选值 | 默认 |
| --- | --- | --- |
| 分辨率 | 1280×720 / 1920×1080 / 2560×1440 / 3840×2160 | 1920×1080 |
| 帧率 | 24 / 25 / 30 / 50 / 60 | 60 |
| 运动模糊 | 关 / 4 / 8 / 16 次采样 | 8 |
| 快门角度 | 90° / 180° / 270° / 360° | 360°（60 fps 下拖影清楚可见） |
| 胶片颗粒 | 0–100 | 30（轻微） |
| 暗角 | 0–100 | 50 |
| 缓动曲线 | 电影 / 标准 / 柔和 / 利落 | 电影：镜头 `cubic-bezier(0.76, 0, 0.24, 1)`，落位 `cubic-bezier(0.16, 1, 0.3, 1)` |
| 码率 | 自动 / 8–80 Mbps | 自动：约 0.2 bit/像素/帧，1080p60 约 25 Mbps |

- 画面按 1920×1080 设计，等比缩放到所选分辨率，文字和线条都按原生分辨率绘制。
- 运动模糊在快门时间内多次采样后取平均。静止段只有 Beni 在慢慢动，所以只采样一次。
- 预览也按所选帧率步进，看到的就是导出的样子。

“导出 MP4”在浏览器里逐帧渲染，再用 WebCodecs 编码成 H.264；浏览器不支持 H.264 时退回 VP9 / AV1，封装用 `vendor/mp4-muxer.js`。导出速度取决于电脑性能，和实时播放流畅与否无关。不支持 WebCodecs 的浏览器会改为实时录制（WebM），录制期间页面需要保持在前台。

产品画面源素材中机身约 780 px 高，1080p 下是缩小显示，很清晰；4K 下机身约放大 1.6 倍，文字和线条仍是原生 4K。

也可以用仓库根目录的逐帧渲染脚本（需要 Node 18+ 和 ffmpeg）：

```bash
npm run beni:render                                                          # → out/beni.mp4，1080p60，8 次运动模糊
node render.mjs --page beni/index.html --size 3840x2160 --fps 30 --blur 16  # 4K30
node render.mjs --page beni/index.html --still 3                             # 某一帧 PNG
```

## 素材

产品画面用的是官网（mondorobotics.com）产品页的移动端渲染序列帧（1170×1800，透明背景），取第 110–152 帧：Beni 站在地上，头从侧面转向镜头。Brief PDF 里的产品图只有 538 px，不够全屏使用。`tools/pack_frames.py` 把这 43 帧裁到可见区域，淡化贴到画面边缘的地面阴影，压成 WebP 写进 `frames.js`。frames.js 内用 base64，所以双击打开也能导出。

## 改什么在哪

都在 `index.html` 的脚本里：

- **参数行**：`ROWS`。
- **版式**：`L`、`R`（左右边距）、`TOP`、`BOT`（上下两条通栏线）、`TR`（表格右边界）、`VX`（数值列），`ROBOT`（Beni 站的位置和缩放）。
- **节奏**：`MOTION = 1.5`、`HOLD = 3.0`；横移距离 `TRUCK`；每行落位的先后在 `drawPage`。
- **Beni 的动作**：`robotFrame(t)`。
- **曲线**：`CURVES`。
- **配色**：强调色 `ACCENT`，背景在 `drawBackground`，文字样式在 `ST`。
