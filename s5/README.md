## 第 2 集 · 传感器与录制规格（18 秒，一镜到底）

画面上不标来源，来源全部在 `evidence/ep2-ledger.csv`。

**主体是 S5 和它的传感器**：S5 是一张去掉镜头的正面照，从头到尾不离开画面，也不换位置，所有信息围着它出现、聚散；镜头是一条连续的推拉（类似 Keynote 的神奇移动：物体保持身份，只有位置、大小、透明度在插值），全片没有一个剪切点。需要讲传感器本身的两段（像素档位横轴、录制区域），镜头推进卡口：照片以传感器玻璃为中心放大、淡出，线稿传感器从同一块玻璃的位置长到全尺寸，两者的轮廓全程重合；回到照片时反过来。**重点是最后一句**：前面的像素和全画幅只是“先立起来再放下”，结尾在传感器上直接画出录制区域——先是 60p 的 APS-C 裁切框，再拉满整块传感器——同时左侧的全部录制规格里亮起那两行。

原文案约 118 字，18 秒要念到每秒 7 字。节拍按下面这版精简口播排（约 100 字，每秒约 6 字），关键词和原文一致：

> S5 用的是一块 2420 万像素全画幅 CMOS。这个像素大家都不陌生，它刚好落在一条平衡线上：照片够用，4K 够用，高感也不错。但像素和全画幅，都不是它真正的卖点。它真正值钱的，是能无裁切录制 C4K 或 4K 30 帧的 4:2:2 10-bit。

## 第 5 集 · 防抖（15.5 秒，三个分镜）

三个分镜之间用 0.4 秒交叉淡化，不硬切；每个分镜先有一小段入场，之后停住让人读。风格沿用第 4 集：细线、灰阶，不加图标和色块。没有提供口播，分镜起止在 `ep5.html` 的 `T`。

| 时间 | 画面 | 证据 |
| --- | --- | --- |
| 0 – 4.5 s | **防抖设置**。左侧五行：机身防抖（5 轴传感器位移，单独约 5 档）、搭配防抖镜头（Dual I.S. 2，合计约 6.5 档）、工作模式（普通 / 摇摄 / 关）、电子防抖（视频）开 / 关、Boost I.S.（视频）开 / 关。右侧示意：L 卡口的圆圈（机身）一直在抖，里面的传感器框不动，下面一行“机身在晃，传感器反向移动抵消” | E01–E05、E07 |
| 4.5 – 9.5 s | **只有机身 vs 机身 + 镜头**，左右对比。左：S5 机身照片、“只有机身防抖”、大字 5 档、“快门可以慢 32 倍”、“例：60 mm 手持，1/60 秒 → 约 1/2 秒”。右：S5 装镜头的照片、“机身 + 镜头一起防抖（Dual I.S. 2）”、大字 6.5 档、“快门可以慢约 90 倍”、“例：200 mm 手持，1/200 秒 → 约 1/2 秒”。两边各一根同一比例的档数条（每格 1 档），右边超出 5 档的 1.5 档更亮，标“多 1.5 档”。底部注明测试条件和需要支持 Dual I.S. 2 的镜头 | E01、E02、E06、E08 |
| 9.5 – 15.5 s | **电子防抖和 Boost I.S.**。左右两个画框。电子防抖：外框（传感器画面）在抖，内框（录下的画面）不动，说明“机身、镜头、电子三者一起修正 5 个方向 / 构图可以移动 / 画面会裁掉一圈，视角变窄”。Boost I.S.：一个不动的画框加中心十字，说明“加大机身防抖的力度 / 只适合固定机位、构图不动 / 要改构图先关掉；焦距越长，效果越弱” | E04、E05 |

**Boost I.S. 不是电子防抖**：官方说法是加强视频时的防抖效果、用于固定机位，它是机身防抖的一种工作方式；真正的电子防抖是“电子防抖（视频）”，会让视角变窄。第三个分镜按这个区别来讲。5 档和 6.5 档的官方测试焦距不同（60 mm / 200 mm），所以两边的例子各按自己的测试焦距换算，结果都约 1/2 秒：加上镜头防抖，焦距长到 200 mm 也能手持到差不多的慢门。

## 预览

直接用 Chrome 或 Edge 打开页面（`s5/index.html`、`s5/ep2.html`）。字体打包成了 data URI，不联网也能看。空格播放/暂停，← → 逐帧，Shift + ← → 跳 1 秒；勾选项可以切换灰盒、朗读提示、遮幅、颗粒和运动模糊。

单文件版：`python3 -I s5/tools/build_single.py [ep2.html | ep3.html | ep4.html | ep5.html]` 把字体、截图、引擎和导出库全部内联进一个文件（`out/s5-storyboard.html` 约 6 MB，`out/ep2-storyboard.html` 约 6 MB，`out/ep3-storyboard.html`、`out/ep4-storyboard.html` 各约 0.5 MB，`out/ep5-storyboard.html` 约 6 MB），拷到哪台电脑都能直接打开。第 1、2、5 集的单文件里有闲鱼截图或相机照片，只在本地传，不进 git。

改过画面上的字要重跑 `python3 -I s5/tools/build_fonts.py`：它扫描所有页面和 `lib/`，生成一份共用的字形子集 `fonts/fonts.js`。

## 导出

**在页面里导出**：预览页下方的“导出视频”。格式可选 MP4（H.264）、WebM（VP9）、PNG 序列；分辨率 1080p / 4K / 720p；帧率 24 / 25 / 30 / 60；码率可调；运动模糊可开关，遮幅和颗粒跟随预览设置。每一帧都按时间重新绘制，不是录屏，所以不会掉帧，任何帧率都准。MP4 / WebM 用浏览器自带的 WebCodecs 编码，需要最新版 Chrome 或 Edge。PNG 序列会让你选一个文件夹逐帧写入；不支持选文件夹的浏览器会打包成 ZIP。

**命令行导出**（做母版用，ffmpeg 编码，标 BT.709；需要 Node 18+、ffmpeg 和 Playwright）：

```bash
node s5/render.mjs                          # 第 1 集 H.264 MP4，24 fps，运动模糊开 → out/s5.mp4
node s5/render.mjs --page ep2.html          # 第 2 集 → out/ep2.mp4
node s5/render.mjs --page ep3.html          # 第 3 集 → out/ep3.mp4
node s5/render.mjs --page ep4.html          # 第 4 集 → out/ep4.mp4
node s5/render.mjs --page ep5.html          # 第 5 集 → out/ep5.mp4
node s5/render.mjs --page ep4.html --still 7.9 --size 3840x2160 --out out/ep4-chart-3840.png   # 第 4 集 4K 定格图
node s5/render.mjs --format prores          # ProRes 422 HQ 10-bit，进剪辑用 → out/s5.mov
node s5/render.mjs --format png             # PNG 序列 → out/s5-frames/
node s5/render.mjs --size 3840x2160         # 4K（任意尺寸，页面按该分辨率重绘）
node s5/render.mjs --fps 60                 # 60 帧
node s5/render.mjs --still 8.42             # 单帧 PNG
node s5/render.mjs --greybox --guide        # 灰盒预览：时间码、镜头号、朗读提示
node s5/render.mjs --letterbox 0 --grain 0 --mb 0
```

页面导出的视频色彩标签是 BT.709 原色 + sRGB 传递函数（浏览器画面本来就是 sRGB）；命令行导出统一标 BT.709。

## 质检

`tools/qc.py` 用测量代替肉眼：编码参数、电平（16–235 为标准，EBU R103 容许 5–246）、示波器，以及按平台常见的 3 Mbps 再压一次后暗部渐变里相同亮度的最长连续像素（色带）。颗粒是直接加在画面上的 0–8 级亮度抖动（背景相应调暗 4 级，平均亮度不变），就是为了压住色带。

```bash
# 第 1 集（默认参数）
node s5/render.mjs --from 5 --to 6 --grain 0 --out out/qc-nograin-5-6s.mp4
python3 -I s5/tools/qc.py s5/out/s5.mp4 --nograin s5/out/qc-nograin-5-6s.mp4           # → out/qc/README.md
# 第 2 集：取 2.0 s 左下方的空白暗部
node s5/render.mjs --page ep2.html --from 1.5 --to 2.5 --grain 0 --out out/ep2-qc-nograin.mp4
python3 -I s5/tools/qc.py s5/out/ep2.mp4 --nograin s5/out/ep2-qc-nograin.mp4 --clip-start 1.5 \
    --at 2.0 --strip 200,900 --rows 760,800,840,880 --out s5/out/qc/ep2
# 第 3 集：取 5.0 s 传感器下方的空白暗部
node s5/render.mjs --page ep3.html --from 4.5 --to 5.5 --grain 0 --out out/ep3-qc-nograin.mp4
python3 -I s5/tools/qc.py s5/out/ep3.mp4 --nograin s5/out/ep3-qc-nograin.mp4 --clip-start 4.5 \
    --at 5.0 --strip 1200,1760 --rows 760,800,840,880 --out s5/out/qc/ep3
# 第 4 集：取 5.0 s 右侧的空白暗部
node s5/render.mjs --page ep4.html --from 4.5 --to 5.5 --grain 0 --out out/ep4-qc-nograin.mp4
python3 -I s5/tools/qc.py s5/out/ep4.mp4 --nograin s5/out/ep4-qc-nograin.mp4 --clip-start 4.5 \
    --at 5.0 --strip 1520,1760 --rows 360,420,480,640 --out s5/out/qc/ep4
# 第 5 集：取 14.0 s 右侧画框外的空白暗部
node s5/render.mjs --page ep5.html --from 13.5 --to 14.5 --grain 0 --out out/ep5-qc-nograin.mp4
python3 -I s5/tools/qc.py s5/out/ep5.mp4 --nograin s5/out/ep5-qc-nograin.mp4 --clip-start 13.5 \
    --at 14.0 --strip 1610,1760 --rows 420,500,580,660 --out s5/out/qc/ep5
```

## 冷启动观众测试

找 3 个没看过文案的人，静音看一遍成片（只看画面），看完马上问。3 个人都答对才算通过；哪一题有 2 个人答错，说明对应镜头读不清：加长停留或放大那一处的字，再测一次。

第 1 集：

1. 这台相机当年的官方定价大约多少？（13,998 元，或“一万四左右”）
2. 它现在二手大约多少？（3,688 元，或“三千六七”）
3. 中间那张表在说什么？（同样能录 4K 60p 10bit 的相机，现在几千元的入门机都有）

第 2 集：

1. S5 的传感器是多少像素？（2420 万，或“两千四百万左右”）
2. 那条横轴想说明什么？（2400 万像素在全画幅里处在中间档，像素大小和细节之间比较平衡）
3. 最后那个框从小变大是什么意思？（录 C4K / 4K 30 帧 4:2:2 10-bit 时用的是整块全画幅，不裁切）

第 4 集：

1. S5 拍 V-Log 时的两个原生 ISO 是多少？（640 和 4000）
2. 这两个数字分别是什么？（两套电路各自的基准感光度：640 是低感，4000 是高感）
3. 上面那几行灰色的是什么？（其他照片风格下的两档基准，V-Log 的最高）

第 5 集：

1. 机身防抖加上镜头防抖最多多少档？（6.5 档）
2. 电子防抖的代价是什么？（画面会裁掉一圈，视角变窄）
3. Boost I.S. 适合什么时候用？（固定机位、构图不动的时候）

## 改什么在哪

- **节奏**：第 1 集是页面顶部的 `T`（镜头起止秒数），第 2 集是字级节拍 `B` 和镜头关键帧 `CAM`；朗读提示 `VO`，时间轴节拍 `BEATS`。
- **第 1 集数据**：`CAMERAS`（对照表）、`LAUNCH`（官方定价）；二手价来自 `evidence/xianyu-sample.csv`，改完重跑 `build_assets.py`，中位数自动重算。
- **第 2 集**：镜头关键帧 `CAM`，推进卡口的节奏 `dive`；数据 `SENSOR`、`ROW`（2400 万像素级机型；`glass`、`body` 是照片里传感器玻璃和机身的像素坐标，换照片要重新量）、`LINE`（像素档位横轴）、`FACTS`（三行）、`MODES`（录制规格，`hl` 标出高亮行，`aps` 是裁切框出现时亮起的 60p 行）。
- **第 4 集**：入场节拍 `B`、定格时长 `DURATION`；数据 `VLOG`（两个原生 ISO 和说明）、`OTHERS`（其他照片风格）、`ISO_MAX`；横轴范围和位置 `AX`。
- **第 5 集**：分镜起止 `T`、交叉淡化 `XF`；数据 `SETTINGS`（第一个分镜的五行）、`COMPARE`（第二个分镜左右两栏：照片、档数、倍数、例子、测试条件）、`MODES`（两种视频防抖的标题和说明）；示意图位置 `MOUNT`、`PHOTO`、`PER_STOP`、`FRAME`，抖动幅度在 `shake()` 的调用处。
- **配色、颗粒、字体**：`lib/stage.js` 里的 `C`、`GRAIN_K`、`F`。

## 文件

- `index.html`、`ep2.html` – `ep5.html`：五集的镜头

- `tools/`：裁切、统计、打包截图、抽取字形、打包单文件、质检的脚本
- `data/sample.js`、`fonts/fonts.js`：生成的数据和字体子集

- `build/`、`out/`：本地生成物，不进 git
