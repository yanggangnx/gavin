# 松下 S5 · 十秒证据镜头

配合一句口播的 10 秒纯 CG 镜头（1920×1080，24 fps，正好 240 帧）。口播本身不上屏：

> 六年，足够让 4K 从旗舰卖点变成基础配置，也足够让一台 14000 元的机身，掉到现在只剩个零头。

画面里只放能复核的物料：发布报道的标题原文、Apple 技术规格、闲鱼截图。每个数字的来源、日期和核实状态都在 `evidence/`（台账 `ledger.csv`，抽样 `xianyu-sample.csv`，说明 `evidence/README.md`）。

## 快速开始

需要 Node 18+、Python 3、ffmpeg 和 Playwright（Chromium）。

```bash
python3 -I s5/tools/crop_xianyu.py     # 从 evidence/raw 裁卡片、打码（只在本地）
python3 -I s5/tools/build_assets.py    # → data/sample.js、build/cards.js
python3 -I s5/tools/build_fonts.py     # 改过画面上的字之后重跑：重新抽取字形
node s5/render.mjs                     # → s5/out/s5.mp4
```

预览：直接用 Chrome 打开 `s5/index.html` 就行（字体和截图都打包成了 data URI，不联网也能看）。空格播放/暂停，← → 逐帧，Shift + ← → 跳 1 秒。下面的勾选项可以切换灰盒、朗读提示、遮幅、颗粒和运动模糊。

## 导出

```bash
node s5/render.mjs                          # H.264 MP4，24 fps，运动模糊开 → out/s5.mp4
node s5/render.mjs --format prores          # ProRes 422 HQ 10-bit，进剪辑用 → out/s5.mov
node s5/render.mjs --format png             # PNG 序列 → out/frames/
node s5/render.mjs --still 8.42             # 单帧 PNG
node s5/render.mjs --greybox --guide        # 灰盒预览：时间码、镜头号、朗读提示
node s5/render.mjs --letterbox 0 --grain 0 --mb 0
```

视频都标成 BT.709（limited range），播放器和剪辑软件按同一套颜色读。颗粒同时起抖动的作用，暗部渐变经过平台二次压缩也不容易出色带。

## 改什么在哪

- **节奏**：`index.html` 顶部的 `T`（每个镜头和事件的秒数）；朗读提示是 `VO`，时间轴上的节拍标记是 `BEATS`。
- **证据文字**：`SLIPS`（2020 年报道）、`SPEC_ROW`（iPhone 17e 规格行）、`HEADLINES`（S3 背景里的标题）；`shot34` 里是价格下方的来源行和标签。改完重跑 `build_fonts.py`。
- **数字**：`LAUNCH`（官方定价）；二手价来自 `evidence/xianyu-sample.csv`，改完重跑 `build_assets.py`，中位数会自动重算。
- **配色**：`C`。字体：`F`（思源宋体 / 思源黑体 / IBM Plex Mono 的子集）。

## 文件

- `index.html`：动画本体和预览播放器
- `render.mjs`：逐帧导出脚本
- `evidence/`：证据台账、抽样表；`raw/` 和 `xianyu/` 是截图，只在本地
- `tools/`：裁切、统计、打包截图、抽取字形的脚本
- `data/sample.js`、`fonts/fonts.js`：生成的数据和字体子集
- `build/`、`out/`：本地生成物，不进 git
