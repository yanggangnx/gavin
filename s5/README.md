# 松下 S5 系列镜头

配合口播的纯 CG 镜头，1920×1080，24 fps，画面 2.39:1 遮幅。口播本身不上屏，画面只放能复核的物料和数据。每条视频一个页面，共用 `lib/stage.js` 里的引擎、预览播放器和导出面板，视觉规则一致：思源宋体 + 思源黑体，左对齐，最多用一次强调色。

| 集 | 页面 | 时长 | 口播 | 证据台账 |
| --- | --- | --- | --- | --- |
| 1 | `index.html` | 10 s（240 帧） | 六年，足够让 4K 从旗舰卖点变成基础配置，也足够让一台 14000 元的机身，掉到现在只剩个零头。 | `evidence/ledger.csv`、`evidence/xianyu-sample.csv` |
| 2 | `ep2.html` | 18 s（432 帧），一镜到底 | S5 用的是一块 2420 万像素全画幅 CMOS……它真正值钱的，是能无裁切录制 C4K 或 4K 30 帧的 4:2:2 10-bit。 | `evidence/ep2-ledger.csv` |

还没有配音，节拍是估算的：第 1 集按每秒约 5 个字，第 2 集按每秒约 6 个字。录配音时打开预览页的“朗读提示”，跟着屏幕底部的字念；录好后按真实波形改页面顶部的 `T`（第 1 集）或字级节拍 `B`（第 2 集）。

## 第 2 集 · 传感器与录制规格（18 秒，一镜到底）

画面上不标来源，来源全部在 `evidence/ep2-ledger.csv`。

**主体是那块传感器**：它从头到尾不离开画面，也不换位置，所有信息围着它出现、聚散；镜头是一条连续的推拉（类似 Keynote 的神奇移动：物体保持身份，只有位置、大小、透明度在插值），全片没有一个剪切点。**重点是最后一句**：前面的像素和全画幅只是“先立起来再放下”，结尾在传感器上直接画出录制区域——先是 60p 的 APS-C 裁切框，再拉满整块传感器——同时左侧的全部录制规格里亮起那两行。

## 预览

直接用 Chrome 或 Edge 打开页面（`s5/index.html`、`s5/ep2.html`）。字体打包成了 data URI，不联网也能看。空格播放/暂停，← → 逐帧，Shift + ← → 跳 1 秒；勾选项可以切换灰盒、朗读提示、遮幅、颗粒和运动模糊。

单文件版：`python3 -I s5/tools/build_single.py [ep2.html]` 把字体、截图、引擎和导出库全部内联进一个文件（`out/s5-storyboard.html` 约 6 MB，`out/ep2-storyboard.html` 约 0.5 MB），拷到哪台电脑都能直接打开。

改过画面上的字要重跑 `python3 -I s5/tools/build_fonts.py`：它扫描所有页面和 `lib/`，生成一份共用的字形子集 `fonts/fonts.js`。

## 导出

**在页面里导出**：预览页下方的“导出视频”。格式可选 MP4（H.264）、WebM（VP9）、PNG 序列；分辨率 1080p / 4K / 720p；帧率 24 / 25 / 30 / 60；码率可调；运动模糊可开关，遮幅和颗粒跟随预览设置。每一帧都按时间重新绘制，不是录屏，所以不会掉帧，任何帧率都准。MP4 / WebM 用浏览器自带的 WebCodecs 编码，需要最新版 Chrome 或 Edge。PNG 序列会让你选一个文件夹逐帧写入；不支持选文件夹的浏览器会打包成 ZIP。

**命令行导出**（做母版用，ffmpeg 编码，标 BT.709；需要 Node 18+、ffmpeg 和 Playwright）：

```bash
node s5/render.mjs                          # 第 1 集 H.264 MP4，24 fps，运动模糊开 → out/s5.mp4
node s5/render.mjs --page ep2.html          # 第 2 集 → out/ep2.mp4
node s5/render.mjs --format prores          # ProRes 422 HQ 10-bit，进剪辑用 → out/s5.mov
node s5/render.mjs --format png             # PNG 序列 → out/s5-frames/
node s5/render.mjs --size 3840x2160         # 4K（任意尺寸，页面按该分辨率重绘）
node s5/render.mjs --fps 60                 # 60 帧
node s5/render.mjs --still 8.42             # 单帧 PNG
node s5/render.mjs --greybox --guide        # 灰盒预览：时间码、镜头号、朗读提示
node s5/render.mjs --letterbox 0 --grain 0 --mb 0
```

页面导出的视频色彩标签是 BT.709 原色 + sRGB 传递函数（浏览器画面本来就是 sRGB）；命令行导出统一标 BT.709。

## 质检

`tools/qc.py` 用测量代替肉眼：编码参数、电平（16–235 为标准，EBU R103 容许 5–246）、示波器，以及按平台常见的 3 Mbps 再压一次后暗部渐变里相同亮度的最长连续像素（色带）。颗粒是直接加在画面上的 0–8 级亮度抖动（背景相应调暗 4 级，平均亮度不变），就是为了压住色带。

```bash
# 第 1 集（默认参数）
node s5/render.mjs --from 5 --to 6 --grain 0 --out out/qc-nograin-5-6s.mp4
python3 -I s5/tools/qc.py s5/out/s5.mp4 --nograin s5/out/qc-nograin-5-6s.mp4           # → out/qc/README.md
# 第 2 集：取 2.0 s 传感器线稿里面的空白暗部
node s5/render.mjs --page ep2.html --from 1.5 --to 2.5 --grain 0 --out out/ep2-qc-nograin.mp4
python3 -I s5/tools/qc.py s5/out/ep2.mp4 --nograin s5/out/ep2-qc-nograin.mp4 --clip-start 1.5 \
    --at 2.0 --strip 1100,1680 --rows 360,440,520,600,680 --out s5/out/qc/ep2
```

当前结果：压缩后有颗粒最长 17 / 14 像素（第 1 / 2 集），无颗粒 248 / 92 像素。

## 冷启动观众测试

找 3 个没看过文案的人，静音看一遍成片（只看画面），看完马上问。3 个人都答对才算通过；哪一题有 2 个人答错，说明对应镜头读不清：加长停留或放大那一处的字，再测一次。

第 1 集：

1. 这台相机当年的官方定价大约多少？（13,998 元，或“一万四左右”）
2. 它现在二手大约多少？（3,688 元，或“三千六七”）
3. 中间那张表在说什么？（同样能录 4K 60p 10bit 的相机，现在几千元的入门机都有）

第 2 集：

1. S5 的传感器是多少像素？（2420 万，或“两千四百万左右”）
2. 那条横轴想说明什么？（2400 万像素在全画幅里处在中间档，像素大小和细节之间比较平衡）
3. 最后那个框从小变大是什么意思？（录 C4K / 4K 30 帧 4:2:2 10-bit 时用的是整块全画幅，不裁切）

## 改什么在哪

- **节奏**：每个页面顶部的 `T`（镜头起止秒数）；朗读提示 `VO`，时间轴节拍 `BEATS`；第 2 集的字级节拍 `B`。
- **第 1 集数据**：`CAMERAS`（对照表）、`LAUNCH`（官方定价）；二手价来自 `evidence/xianyu-sample.csv`，改完重跑 `build_assets.py`，中位数自动重算。
- **第 2 集**：镜头关键帧 `CAM`；数据 `SENSOR`、`ROW`（2400 万像素级机型）、`LINE`（像素档位横轴）、`FACTS`（三行）、`MODES`（录制规格，`hl` 标出高亮行，`aps` 是裁切框出现时亮起的 60p 行）。
- **配色、颗粒、字体**：`lib/stage.js` 里的 `C`、`GRAIN_K`、`F`。

## 文件

- `index.html`、`ep2.html`：两集的镜头
- `lib/stage.js`：共用引擎（绘制、颗粒、运动模糊）、预览播放器、导出面板、`window.__motion` 渲染接口
- `render.mjs`：逐帧导出脚本，`--page` 选集
- `evidence/`：证据台账、抽样表；`raw/` 和 `xianyu/` 是截图，只在本地
- `tools/`：裁切、统计、打包截图、抽取字形、打包单文件、质检的脚本
- `data/sample.js`、`fonts/fonts.js`：生成的数据和字体子集
- `vendor/`：mp4-muxer 5.2.2、webm-muxer 5.1.4（MIT，页面导出用）
- `build/`、`out/`：本地生成物，不进 git
